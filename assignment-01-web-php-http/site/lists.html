Ordered List — Penetration Testing Steps

  1. Reconnaissance — gather information about the target
  2. Scanning — enumerate open ports, services, and technologies
    1. Port scanning (Nmap)
    2. Service version detection
    3. Vulnerability scanning (Nikto, ZAP)
  3. Gaining Access — exploit identified vulnerabilities
    1. SQL injection
    2. Cross-site scripting
    3. Authentication bypass
  4. Maintaining Access — establish persistence (lab only)
  5. Reporting — document findings with evidence
  6. Remediation — apply and verify fixes

Definition List — Key Security Terms

XSS (Cross-Site Scripting)
Injection of client-side scripts into web pages viewed by other users. Can steal cookies, deface pages, or redirect users.
SQLi (SQL Injection)
Insertion of malicious SQL code into queries via unvalidated user input. Can expose, modify, or delete database contents.
CSRF (Cross-Site Request Forgery)
Attack that tricks a victim's browser into making authenticated requests to a site the victim is logged into.
Allowlist
A set of explicitly permitted values; anything not on the list is denied. Preferred over blacklisting for input validation.
Prepared Statement
A parameterized SQL query where user input is passed separately from the SQL structure, preventing injection.
CVSS
Common Vulnerability Scoring System — a standardized framework for rating the severity of security vulnerabilities on a 0–10 scale.
